# Histórico do estudo

**Agosto de 2026 — início do projeto.** O estudo começou com a investigação de embeddings de imagens e comparação entre métodos baseados em distância para classificação multiclasse. Um registro de avaliação disponível no material de trabalho é datado de agosto de 2026; esse registro não representa um histórico completo de commits.

**Evolução posterior.** O material foi organizado em scripts independentes, testes de métricas, verificações de integridade e documentação. A preparação para repositório público removeu resultados e materiais de terceiros cuja publicação não havia sido autorizada.

Os commits do GitHub registram a data real de cada publicação; não são retrodatados para simular a cronologia do desenvolvimento. Novas mudanças serão documentadas conforme forem realizadas.
